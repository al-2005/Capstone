# Demo deliverables

- `presentation.pptx` — capstone presentation slide deck.
- `campus-helpdesk-demo.mp4` — record and add the real walkthrough here before submission.
- `RECORDING.md` — required video order and capture checklist.
- `../docs/screenshots/` — terminal, application, CI/CD, infrastructure, cluster, and monitoring
  evidence captured from actual runs.

The MP4 is intentionally not generated as a substitute for a real walkthrough. It must show the
actual repository, live workflows, and deployed services described in the submission guidelines.
